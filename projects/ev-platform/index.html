How it works

Airflow lands each source only when it changes. SQL models in PostgreSQL build Bronze, Silver and Gold, and a separate stream keeps charger availability live. Select a component to see what it does.

One platform, two kinds of user

Drivers

  • Chargers that fit the car's connector, near a point or along a trip
  • Price, plugs and live availability from the operators' own feeds
  • A 3D preview of the drive, and questions answered in plain language

Operators

  • A daily run that skips any source whose content has not changed
  • Quality checks that fail the run before bad data reaches a report
  • Lineage from source file to report, with Grafana and Slack alerts
